# SEO Checklist - Luan Allround Service

## Monthly SEO Tasks

### Content & On-Page SEO
- [ ] Publish 1-2 new blog posts with local keywords
- [ ] Update existing blog posts with fresh information
- [ ] Check and optimize meta descriptions for top pages
- [ ] Review and update service page content
- [ ] Add new project images to gallery
- [ ] Optimize new images with descriptive alt text
- [ ] Review internal linking structure
- [ ] Check for broken links using Google Search Console

### Technical SEO
- [ ] Run Lighthouse audit on main pages
- [ ] Check Core Web Vitals in Search Console
- [ ] Validate schema markup with Google Rich Results Test
- [ ] Review sitemap.xml and submit any updates
- [ ] Check robots.txt accessibility
- [ ] Monitor site speed with PageSpeed Insights
- [ ] Test mobile-friendliness
- [ ] Check for crawl errors in Search Console

### Local SEO
- [ ] Post update on Google Business Profile
- [ ] Reply to all Google reviews (aim to respond within 24 hours)
- [ ] Add new project photos to Google Business Profile
- [ ] Update business hours if changed
- [ ] Create local content targeting nearby cities
- [ ] Submit to or update local directories
- [ ] Check NAP (Name, Address, Phone) consistency online

### Analytics & Monitoring
- [ ] Review Google Analytics traffic trends
- [ ] Analyze top-performing pages and keywords
- [ ] Review Search Console performance report
- [ ] Check impressions and click-through rates
- [ ] Monitor average position for target keywords
- [ ] Track conversion rate from forms
- [ ] Identify pages with high bounce rates
- [ ] Review referral sources

### Link Building
- [ ] Reach out to 3-5 local businesses for partnerships
- [ ] Submit to quality local directories (if not done)
- [ ] Check backlink profile for toxic links
- [ ] Create shareable content (guides, infographics)
- [ ] Engage with local community pages

## Quarterly SEO Tasks

### Content Audit
- [ ] Review all blog posts for relevance
- [ ] Update outdated statistics or information
- [ ] Merge or redirect thin content pages
- [ ] Identify content gaps based on keyword research
- [ ] Plan content calendar for next quarter

### Technical Audit
- [ ] Full site crawl with Screaming Frog (or similar)
- [ ] Review site architecture and URL structure
- [ ] Check for duplicate content issues
- [ ] Audit all redirects (301, 302)
- [ ] Review HTTPS implementation
- [ ] Check XML sitemap accuracy
- [ ] Validate all schema markup

### Competitor Analysis
- [ ] Identify top 5 local competitors
- [ ] Analyze their keyword rankings
- [ ] Review their content strategy
- [ ] Check their backlink profile
- [ ] Identify opportunities to outrank them

### Local SEO Deep Dive
- [ ] Audit all local citations
- [ ] Update business listings on all platforms
- [ ] Optimize Google Business Profile fully
- [ ] Collect customer reviews (aim for 2-3/month)
- [ ] Create location-specific landing pages
- [ ] Target "near me" searches
